# Документация проекта

Документация разделена на две категории:

## `spec/` — технические спецификации

Строгие технические описания каждого компонента: контракты API, схемы данных, формат файлов
на диске, инварианты, граничные случаи. Пишется от реализации, для разработчика, который будет
этот модуль дорабатывать или интегрировать. Один файл — один компонент (`spec/<component>.md`).
Каждая спецификация самодостаточна. Карта компонентов — [`spec/README.md`](spec/README.md).

## `guide/` — гайды и туториалы

Объясняющие материалы: как устроена та или иная технология, как ей пользоваться, пошаговые
примеры. Пишется для человека, который знакомится с темой. Может быть и не про код проекта напрямую
(напр. общий разбор формата), но с секцией о том, как это применяется в проекте.

| Файл | О чём |
|---|---|
| [`guide/sigma-rules-guide.md`](guide/sigma-rules-guide.md) | Полный разбор формата Sigma-правил (структура, `detection`, модификаторы, корреляции, фильтры) |
| [`guide/correlation-rules-guide.md`](guide/correlation-rules-guide.md) | Практический гайд по сценарным (correlation) правилам ЭТОГО проекта — как писать, сохранять, включать, четыре типа на примерах, ограничения |
| [`guide/mitre-attack-guide.md`](guide/mitre-attack-guide.md) | MITRE ATT&CK: модель, объекты, версии, STIX, как это используется во вкладке «База знаний» |
| [`guide/forwarder.md`](guide/forwarder.md) | Протокол потокового ingest для форвардеров (`POST /ingest/stream`) |
